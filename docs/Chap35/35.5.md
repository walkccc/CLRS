## 35.5-4

> How would you modify the approximation scheme presented in this section to ﬁnd a good approximation to the smallest value not less than $t$ that is a sum of some subset of the given input list?

Instead of maintaining under-estimates $z$, maintain over-estimates $z$ satisfying 

$$y \le z \le (1+\delta) y$$

We can't remove from $L_i$ every element greater than $t$, because our solution candidates are $\ge t$. However, at each step $i$, we can keep $u_i$, the least element in $L_i$ that is still at least $t$, and remove all elements greater, as those can only generate subset sums larger than $u_i$.

Modify TRIM to iterate in decreasing order, maintaining $last$ and $y_i$ if $y_i < last / (1 + \delta)$. 

A similar spacing argument shows the $L_i$ values $< t$ are spaced out by geometric spacing of factor $1 + \delta$, and so their count is limited by $O((n \ln t)/\epsilon)$, and there is at most one element $u_i \ge t$ kept.

A similar induction shows optimal sum $y^* \ge t$ is approximated by $z^* \in L_n$ satisfying $t \le y^* \le z^* \le (1 + \delta)^n y^* \le (1 + \epsilon) y^*$.
