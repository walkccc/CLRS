## 35.3-3

> Show how to implement $\text{GREEDY-SET-COVER}$ in such a way that it runs in time $O\Big(\sum_{S \in \mathcal F} |S|\Big)$.

The algorithm is similar to a naive implementation, except care is taken to iterate over only each element in each $S$ once.

WLOG, let $X = \\{1, \dots, n\\}$ and $\mathcal F = \\{ S_1, \dots, S_k \\}$. Let $t = \sum_{S \in \mathcal F} |S|$.

We use a doubly linked list data structure with $O(1)$ iteration per element and $O(1)$ removal via pointer.

Maintain 
- for each $S_i$, list $A_i$ containing the uncovered elements of $S_i$ in this iteration
- for each $j$ with $1 \le j \le n$, list $B_j$ containing pointers to element $j$ in $A_i$, for every $A_i$ which contains $j$
- for each $m$ with $0 \le m \le n$, list $M_m$ containing pointers to $A_i$ satisfying $|A_i| = m$
- $m^\ast$, tracking the largest $m$ such that $M_m$ is non-empty (so we can track the largest $A_i$)

Initialize all $A_i, B_j, M_m$ in $O(t)$ time.

While $m^* > 0$ (meaning there are still non-empty $A_i$):

1. Pick arbitrary (pointer to) $A_{i^\ast}$ from $M_{m^\ast}$ and add $S_{i^\ast}$ to the cover $\mathcal C$
2. For each $j$ in $A_{i^\ast}$:
    1. For each pointer in $B_j$:
        1. Let $m = |A_i|$
        2. Remove via pointer the $j \in A_i$
        3. Move the pointer to $A_i$ from $M_{m}$ to $M_{m-1}$ (in effect, decrementing $A_i$'s size)
3. While $M_{m^\ast}$ is empty and $m^\ast > 0$, decrement $m^\ast$ (to get to the next largest set size)

The algorithm performs $O(1)$ operations for every element $j$ in every $S_i$, never iterating over an already considered element. $m^*$ is decremented at most $n$ times. Therefore the total runtime is $O(t)$.
