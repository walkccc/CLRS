## 35.3-3

> Show how to implement $\text{GREEDY-SET-COVER}$ in such a way that it runs in time $O\Big(\sum_{S \in \mathcal F} |S|\Big)$.

WLOG, let $X = \\{1, \dots, n\\}$ and $\mathcal F = \\{ S_1, \dots, S_k \\}$. Let $t = \sum_{S \in \mathcal F} |S|$.

We use a linked list data structure with $O(1)$ iteration per element and $O(1)$ removal via pointer.

Maintain 
- for each $S_i$, list $A_i$ representing the uncovered elements of $S_i$
- sizes $m_i = |A_i|$ and $M = \max_i m_i$
- for each $j$, list $B_j$ representing which $i$ still have $j \in A_i$, along with pointers to those $j$ into $A_i$ for fast access

Initialize all $A_i, B_j, m_i, M = \max_i m_i, i^* = \arg\max_i m_i$ in $O(t)$ time.

While $M > 0$:

- For each element $j$ of $A_{i^*}$:
    - Iterate over $B_j$ to find which $A_i$ have $j$ in them
      - remove those $j$ from $A_i$, decrementing $m_i$. Meanwhile update new $M$ and $i^*$


For each iteration of the loop, for each element $j \in S_{i^*}$, the $j$ in all $S_i$ are iterated and removed once. Therefore since $O(1)$ operations are for all elements in all $S_i$, the runtime is $O(t)$.
